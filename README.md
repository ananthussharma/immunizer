# Immunizer — Vite + Vue Demo

Quick demo app to view vaccination details.

Run locally:

```bash
npm install
npm run dev
```

Routes:
- `/` — Login
- `/register` — Registration
- `/dashboard` — User dashboard (requires login)
- `/vaccine/:vaccineId` — Vaccine details
- `/booster/:boosterId` — Booster details

API base: `http://localhost:8080/vaccinator`
